# Pinder

Комплексная реализация мобильного приложения знакомств Pinder на стеке React Native и Expo SDK 57 в строгом соответствии с дизайн-системой и UI-Kit.

## Стек технологий

- React Native 0.86.3
- Expo SDK 57.0.26
- React 19.2.3
- TypeScript 6.0.3
- react-native-svg 15.15.4
- expo-linear-gradient 57.0.2

## Экраны и функциональность

1. **Первоначальный экран (`WelcomeScreen`)**:
   - Брендинг `pinder` и фирменная типографика Georgia / Serif.
   - Слайдер преимуществ с точечной пагинацией.
   - Переходы к регистрации, авторизации и быстрый вход в гостевой демо-режим.
2. **Экран входа (`LoginScreen`)**:
   - Поля ввода email/телефона и пароля с кнопкой показа/скрытия.
   - Переключатель «Запомнить меня» и ссылка «Забыли пароль?».
   - Адаптация под сенсорный ввод и автоматический сдвиг при открытии клавиатуры (`KeyboardAvoidingView`).
3. **Экран регистрации (`RegisterScreen`)**:
   - 3-шаговый мастер с индикатором прогресса:
     1. Личные данные и возраст 18+.
     2. Пол, предпочтения поиска, биография.
     3. Выбор аватара из галереи пресетов и выбор до 5 тегов интересов.
4. **Главная лента (`FeedScreen`)**:
   - Свайпы карточек влево (пропуск), вправо (лайк) и вверх (суперлайк) через PanResponder.
   - Вращение карточки с интерполяцией и динамические штампы НОРМ / СТРЁМ.
   - Модальное окно фильтрации поиска по нажатию на иконку фильтра в хедере.
   - Модальное окно празднования взаимного совпадения «Это взаимно!» с кнопкой перехода в чат.
5. **Экран симпатий (`LikesScreen`)**:
   - Вкладки переключения «Все симпатии» и «Взаимно».
   - Двухколоночная адаптивная сетка карточек с фото, возрастом и бейджами.
   - Быстрые действия прямо на карточках: «Ответить взаимностью», «Написать», «Пропустить».
   - Просмотр подробной анкеты в BottomSheet по тапу на карточку.
6. **Экран списка диалогов (`ChatsScreen`)**:
   - Верхняя горизонтальная карусель «Новые пары» (Stories-формат) с подсветкой.
   - Поисковая строка для мгновенной фильтрации по имени или тексту сообщений.
   - Список диалогов со статусом «В сети», сниппетом последнего сообщения, временем и счетчиком непрочитанных.
7. **Экран диалога с собеседником (`ChatDialogScreen`)**:
   - История переписки с разделением на входящие (белые) и исходящие (фирменный Coral) облачка сообщений.
   - Временные метки и индикатор доставки ✓✓.
   - Быстрые заготовки реплик и тем для разговора (айсбрейкеры).
   - Кнопка аудиозвонка с интерактивным вызовом.
   - Реалистичная имитация автоответа: при отправке сообщения собеседник показывает статус «печатает...» и отвечает через 1.4 секунды!
8. **Экран профиля (`ProfileScreen`)**:
   - Личная карточка: крупный аватар со статусом активности, имя, город, биография, интересы.
   - Блок статистики: количество отправленных симпатий, взаимных совпадений, процент заполнения анкеты.
   - Интерактивный режим редактирования: смена фото, имени, возраста, био, включение/выключение тегов.
   - Режим «Предпросмотр карточки» (как ваша анкета выглядит для других пользователей в колоде ленты).
9. **Экран настроек (`SettingsScreen`)**:
   - Фильтры поиска: предпочтения по полу, слайдер максимального расстояния (1–100 км), слайдер возраста (18–55 лет).
   - Управление уведомлениями (новые пары, сообщения, вибрация).
   - Приватность: режим «Невидимка» (скрытие из ленты), показ онлайн-статуса.
   - Управление аккаунтом: сброс истории свайпов, выход из профиля, удаление аккаунта.

## Учет особенностей мобильных устройств

- **Безопасные зоны (`SafeAreaView`)**: учет вырезов фронтальной камеры, «челок», Dynamic Island и нижнего Home-бара на iOS и Android.
- **Эргономика тача (Touch Targets)**: все интерактивные элементы имеют размер кликабельной зоны не менее 44×44 pt и обратную связь через `activeOpacity`.
- **Работа с клавиатурой**: применение `KeyboardAvoidingView` с правильными режимами сдвига и автоматическое закрытие клавиатуры при тапе в свободную область экрана.
- **Типографика и платформенные стили**: Georgia на iOS и системный Serif на Android для логотипа и имен, четкий Sans для интерфейса; тени через `shadow*` на iOS и `elevation` на Android.

## Запуск и разработка

Установка зависимостей:
```bash
npm install
```

Запуск сервера разработки Metro:
```bash
npx expo start -c
```

Команды целевых платформ:
- `w` — запуск в веб-браузере
- `a` — запуск в Android Emulator
- `i` — запуск в iOS Simulator
- QR-код в терминале — запуск в Expo Go на физическом смартфоне

Проверка статической типизации:
```bash
npx tsc --noEmit
```
