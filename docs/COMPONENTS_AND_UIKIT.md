# Компоненты и UI-Kit (`src/components/`)

В проекте Pinder разработана собственная модульная библиотека компонентов, разделенная на атомарные элементы интерфейса (`src/components/ui/`) и предметные компоненты (`src/components/`).

---

## 1. Атомарные компоненты UI-Kit (`src/components/ui/`)

### 1.1. `Button.tsx` — Универсальная кнопка

Поддерживает 4 визуальных стиля и 3 типоразмера:
- **Варианты (`variant`):**
  - `primary` — фирменная коралловая заливка (`#FF5757`) с белым текстом.
  - `secondary` — мягкая персиковая/кремовая заливка (`#FFF0ED`) с коралловым текстом.
  - `outline` — прозрачный фон с тонкой рамкой `#E8DFD8`.
  - `ghost` — минималистичная кнопка без фона и рамок.
- **Размеры (`size`):** `sm` (высота 36pt), `md` (высота 46pt), `lg` (высота 54pt, радиус скругления 27pt).
- **Состояния:** Индикатор загрузки (`loading` через `ActivityIndicator`), заблокированное состояние (`disabled`), поддержка иконок слева (`leftIcon`) и справа (`rightIcon`).

### 1.2. `Input.tsx` — Поле ввода текста

Текстовое поле с продвинутой поддержкой состояний фокуса и валидации:
- **Поддержка заголовка (`label`):** Поясняющая надпись над инпутом.
- **Отображение ошибок (`error`):** Подсветка рамки тревожным цветом и вывод текста ошибки под полем.
- **Скрытие пароля (`isPassword`):** Встроенная кнопка-глазок для безопасного ввода и просмотра пароля.
- **Быстрая очистка (`clearable`):** Кнопка-крестик для мгновенного стирания введенного текста.
- **Иконки:** Слот `leftIcon` для векторных значков (`SearchIcon`, `LockIcon`, `UserIcon`).

### 1.3. `Slider.tsx` — Сенсорный ползунок

Пользовательский слайдер с поддержкой жестов и дискретного шага:
- **Двойной ввод жестов через `PanResponder`:**
  - Плавное перетаскивание круглого бегунка пальцем.
  - Мгновенный перенос значения при тапе в любую точку дорожки.
- **Шаговые кнопки `+` и `−`:** Позволяют ювелирно изменить значение на 1 единицу без перетаскивания.
- **Быстрые пресеты (`quickPresets`):** Набор чипов (например: `10, 25, 50, 100 км`) для выбора стандартных значений в один клик.

### 1.4. `Switch.tsx` — Интерактивный переключатель

Компактный тумблер с плавной пружинной анимацией смещения кругляшка:
- При переключении в состояние `true` дорожка окрашивается в коралловый цвет `#FF5757`.
- Бегунок анимируется через `Animated.spring` с естественной физикой упругости.

### 1.5. `Badge.tsx` — Бейджи и чипы интересов

- **Варианты:**
  - `tag` — капсула с тегом интереса (например, «кофе & прогулки»). В активном состоянии подсвечивается коралловым фоном.
  - `count` — круглый бейдж количества непрочитанных сообщений или взаимных пар.
  - `status` — статусный индикатор.
  - `verified` — золотистый бейдж верификации анкеты.

### 1.6. `Avatar.tsx` — Аватар пользователя

- **Размеры:** `sm` (36×36), `md` (52×52), `lg` (72×72), `xl` (96×96).
- **Индикатор «В сети»:** Зеленая точка активности `#27AE60` с белой окантовкой в правом нижнем углу.
- **Фоллбэк:** При отсутствии фотографии отображаются инициалы пользователя на градиентном фоне.

### 1.7. `SegmentedControl.tsx` — Таб-переключатель

Типизированный переключатель вкладок (`<T>`):
- Плавное визуальное переключение активной вкладки.
- Поддержка числовых бейджей на отдельных вкладках (например: «Все симпатии (12)» и «Взаимно (4)»).

### 1.8. `Modal.tsx` — Модальное окно и BottomSheet

- Вариант всплывающего окна по центру экрана (`center`).
- Вариант шторки, выезжающей снизу (`bottomSheet`), с полупрозрачным затемняющим оверлеем (`Backdrop`) и закрытием по клику вне контента.

## 2. Составные компоненты приложения (`src/components/`)

### 2.1. `Card.tsx` — Карточка анкеты в ленте
Главный визуальный компонент Pinder:
- Полноразмерная фотография профиля с соотношением сторон для современных безрамочных дисплеев.
- Тройной вертикальный градиент (`LinearGradient`): предотвращает засветку белого текста на светлых фотографиях.
- **Динамические штампы лайка и дизлайка:**
  - Зеленый штамп «НОРМ» / «LIKE» (наклон -15°, проявляется при смещении вправо).
  - Красный штамп «СТРЁМ» / «NOPE» (наклон +15°, проявляется при смещении влево).
  - Голубой штамп «СУПЕРЛАЙК» (проявляется при смещении вверх).
- Текстовый блок: Имя, возраст, расстояние, город, профессия, биография и теги интересов.

### 2.2. `ActionButtons.tsx` — Панель кнопок свайпа
Нижний блок с тремя крупными круглыми кнопками:
1. **Дизлайк (Крестик):** Белый фон, серая окантовка, иконка `#737373`.
2. **Суперлайк (Звезда):** Голубой оттенок, размер поменьше, иконка `#4A90E2`.
3. **Лайк (Сердце):** Фирменный коралловый цвет `#FF5757`, крупный размер (64×64 pt) с мягкой тенью.

### 2.3. `Header.tsx` — Верхняя панель ленты
- Слева: круглый мини-аватар текущего пользователя для быстрого перехода в профиль.
- По центру: логотип `pinder` в засечном стиле.
- Справа: кнопка с иконкой фильтра для вызова `FilterModal`.

### 2.4. `BottomNavBar.tsx` — Нижняя навигационная панель
Панель переключения между 3 вкладками приложения:
1. **Лента (`feed`):** Иконка карточек/огня.
2. **Симпатии (`likes`):** Иконка сердечка с бейджем входящих лайков.
3. **Чаты (`chats`):** Иконка диалогов с бейджем суммарного количества непрочитанных сообщений.

### 2.5. `MatchModal.tsx` — Окно празднования совпадения
Полноэкранное праздничное окно, открывающееся при возникновении взаимной пары:
- Круглые фотографии обоих пользователей, пересекающиеся по центру.
- Анимированное пульсирующее сердце между фотографиями (`HeartFilledIcon` с анимацией масштабирования).
- Конфетти-эффект и две кнопки: «Написать первое сообщение» и «Продолжить поиск».

### 2.6. `FilterModal.tsx` — Шторка параметров поиска
Быстрая настройка фильтров прямо из ленты: выбор пола, слайдер радиуса поиска и диапазона возраста без необходимости переходить в полный экран настроек.

### 2.7. `ScreenTransition.tsx` — Анимация смены экранов
Обертка над навигатором, плавно анимирующая появление нового экрана:
- `opacity`: от `0` до `1` за 200 мс (`Animated.timing`).
- `translateY`: пружинный подъем на 10 пикселей (`Animated.spring`).
- `scale`: микро-масштабирование от `0.985` до `1.0`.

### 2.8. `Icons.tsx` — Векторные SVG-иконки
Набор оптимизированных векторных иконок на базе `react-native-svg`:
- Не зависят от растровых ассетов и четко масштабируются под любые экраны (@1x, @2x, @3x).
- Поддерживают произвольные параметры `size` и `color`.
- Включают: `HeartFilledIcon`, `HeartOutlineIcon`, `CrossIcon`, `StarIcon`, `SparklesIcon`, `ChatBubbleIcon`, `UserIcon`, `SettingsIcon`, `FilterIcon`, `SearchIcon`, `CameraIcon`, `PhoneIcon`, `LockIcon`, `BellIcon`, `CheckIcon`, `CheckCheckIcon`, `LogoutIcon` и др.
